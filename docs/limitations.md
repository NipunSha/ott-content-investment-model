# Limitations
1. Most inputs are assumptions with ranges; results are conditional statements, not forecasts.
2. Incremental subscribers are an input. No public data identifies title-level subscriber attribution for Indian platforms.
3. Sources S02, S04, S05 and S06 were read through search-result summaries, not fetched directly; S04 is context only and is not a model input.
4. The FICCI-EY implied ARPU (INR163bn / 216m / 12) mixes video with other digital subscriptions and is an upper bound for video.
5. Co-production terms are not tested from the partner's side.
6. One title in isolation: no portfolio diversification, cannibalisation between titles or catalogue depth effects.
7. Residual rights value is a single number standing in for sequel, remake and library value.
8. Monte Carlo distributions are judgemental. Inputs are drawn independently apart from the shared title-performance draw.
9. No Tableau workbook has been built; `tableau/` contains data and a specification only.
